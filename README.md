# Протоколи ведення вагітності

Веб-сайт з інтерактивними таймлайнами вагітності за трьома медичними протоколами:
- Український (Наказ МОЗ №1437)
- Британський (NICE NG201)
- Американський (ACOG)

Реалізовано на React + Vite за дизайн-референсами з `design_handoff_pregnancy_protocols`.

## Розробка

```bash
npm install
npm run dev
```

## Білд

```bash
npm run build
```

Деплой на GitHub Pages відбувається автоматично через GitHub Actions при пуші в `main`.
